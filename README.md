# BankSync
**Version:** v1.2.0  
**Author:** MA
## 功能
- 一键登录银行
- 批量下载银行流水、回单、对账单（支持>3个月）
- 筛选导出银行利息Excel
- 集成AI助手
- 待办管理、日志查看
- 邮件自动下载
